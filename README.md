# Fair Studio

Web corporativa de **Fair Studio**, estudio ficticio de desarrollo de webs y apps móviles (proyecto de Sostenibilidad, 1º DAW).
React + Vite, react-router (HashRouter), motion. Iconos Majesticons (icons0.dev, MIT).

- `/` landing corporativa · `/#/politicas` Política ASG y tabla ASG–ODS
- Desarrollo: `npm install && npm run dev`
- Docker: `docker build -t fair-studio . && docker run -d -p 8080:80 fair-studio`
- GitHub Pages: rama `gh-pages` con el contenido de `dist/` (`npm run build`).
